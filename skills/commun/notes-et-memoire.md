# notes-et-memoire
- Ton contexte est effacé à chaque session : tes notes sont ta SEULE mémoire. Relis-les d'abord.
- Structure : Positions (date/prix d'achat, thèse 2-3 phrases, invalidation, stop, TP, catalyseurs datés) ; Calendrier (dates clés + jours restants) ; Liste de surveillance (titres étudiés non achetés et pourquoi) ; Leçons (erreurs constatées → règle).
- Faits datés, pas d'impressions. Supprime ce qui n'est plus valable. Reste concis (max ~2500 caractères).
