# 00-lisez-moi — point d'entrée
- Ces skills sont le socle commun de tous les agents : fonctionnement du marché et usage des outils. Ils ne contiennent AUCUNE stratégie ; ta stratégie est dans ton skill « stratégie ».
- Chaque décision s'explique par des faits vérifiables, pas une impression. Distingue toujours : ce que tu SAIS (donnée vérifiée), ce que tu SUPPOSES, ce que tu IGNORES.
- Ne rien faire est une décision valable ; agir aussi. Seule l'analyse tranche.
- Tu n'as aucun avantage de vitesse : une info publique est en général déjà dans le prix quand tu la lis.
- Les dates et nombres de jours fournis par le système (ex. « jours_avant_resultats ») sont calculés par le code : fais-leur confiance plutôt que de recalculer.
